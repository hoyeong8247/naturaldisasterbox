# NaturalDisasterBox website starter

## Files
- `index.html`: public channel/service information
- `privacy.html`: privacy policy starter draft
- `terms.html`: terms of service starter draft
- `assets/style.css`: shared styling

## Before publishing
1. Contact email is set to `naturaldisasterbox@app.com`. Confirm that this inbox is monitored.
2. Review the Privacy Policy against the actual TikTok, n8n, Google Drive, hosting, and OAuth data flows. Add accurate retention periods and contact details; remove anything that does not apply.
3. Review the Terms for your actual operation and applicable law.
4. Do not describe this as a public creator service if it is only used internally. The website must accurately describe the real service and intended users.
5. TikTok's API approval is separate from having a website. A website does not override TikTok's restrictions on internal-use posting utilities.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `naturaldisasterbox-site`.
2. Upload all files and folders while preserving the structure.
3. In repository Settings > Pages, select Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to become available.
6. Test the homepage, `/privacy.html`, and `/terms.html` in a private/incognito browser window.
7. Use the exact live URLs in the developer app form.

Do not publish the placeholder contact email or submit the draft legal pages until reviewed and completed.
